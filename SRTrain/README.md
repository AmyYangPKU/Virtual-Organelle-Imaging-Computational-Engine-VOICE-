# SRTrain: 2D RCAN Image Restoration Training

`SRTrain` provides a two-dimensional, single-channel image restoration training pipeline based on the **Residual Channel Attention Network (RCAN)**. It is designed to restore low-quality (LR) images to their corresponding high-quality (SR) targets.

## Directory Contents

```text
SRTrain/
├── RCAN2D.py   # RCAN2D network architecture
├── train.py    # Data loading, training, validation, testing, and checkpointing
└── README.md
```

## Environment Setup

Python 3.10 is recommended. Create and activate a dedicated Conda environment:

```bash
conda create -n rcan2d python=3.10 -y
conda activate rcan2d
```

First install the appropriate PyTorch build for your CPU or CUDA environment, and then install the remaining dependencies:

```bash
python -m pip install torch torchvision
python -m pip install numpy tifffile pillow tqdm kornia pytorch-msssim scikit-image
```

## Dataset Structure

The `--dataset` argument must point to the dataset root. The training and validation sets are required, while the test set is optional:

```text
dataset_root/
├── train/
│   ├── LR/                 # Low-quality training images
│   │   ├── image_001.tif
│   │   └── image_002.tif
│   └── SR/                 # Corresponding high-quality training images
│       ├── image_001.tif
│       └── image_002.tif
├── val/
│   ├── LR/
│   └── SR/
└── test/                   # Optional; 
    ├── LR/
    └── SR/
```

Dataset requirements:

- Images must use the `.tif` or `.tiff` format.
- LR and SR files are paired according to their sorted filenames. Both directories must contain the same number of files and matching filenames.
- The current model configuration uses one input channel and one output channel.
- Set `scale_factor` in `train.py` to match the actual upsampling factor of the dataset.
- LR and SR images should use consistent value ranges and bit depths.

## Training

Enter the `SRTrain` directory:

```bash
cd /path/to/Virtual-Organelle-Imaging-Computational-Engine-VOICE--main/SRTrain
```

Start training from scratch:

```bash
python train.py \
  --dataset /path/to/dataset_root \
  --save_dir /path/to/training_output \
  --epochs 40
```

### Command-Line Arguments

| Argument | Required | Description |
| --- | --- | --- |
| `--dataset` | Yes | Path to the dataset root |
| `--save_dir` | Yes | Directory for checkpoints, logs, and test results |
| `--epochs` | No | Number of training epochs; defaults to 40 |
| `--pretrained` | No | Path to a pretrained RCAN checkpoint (`.pth`) |
| `--finetune` | No | Enables fine-tuning mode and reduces the learning rate to one tenth of its default value |

## Fine-Tuning from a Pretrained Checkpoint

```bash
python train.py \
  --dataset /path/to/dataset_root \
  --save_dir /path/to/finetune_output \
  --pretrained /path/to/best_rcan.pth \
  --finetune \
  --epochs 20
```

The pretrained checkpoint must use the same `RCAN2D` architecture as the current model.

## Outputs

Training results are written to the directory specified by `--save_dir`:

```text
training_output/
├── loss_log.txt             # Training configuration and per-epoch metrics
├── rcan_epoch1.pth          # Model checkpoint from each epoch
├── rcan_epoch2.pth
├── ...
├── best_rcan.pth            # Checkpoint with the lowest validation loss
├── best_ssim_rcan.pth       # Checkpoint with the highest validation MS-SSIM
└── best_ssim_test_SR/       # Test outputs generated by the best MS-SSIM model
    ├── 1.tif
    └── ...
```


If no `test/` dataset is provided, test evaluation and test image export are skipped automatically.

## Current Default Configuration

The following settings are currently defined directly in `train.py`:

| Setting | Default value |
| --- | --- |
| Batch size | 8 |
| Learning rate | `2e-4` |
| Optimizer | Adam |
| Scale factor | 1 |
| Device | CUDA when available; otherwise CPU |

To change the batch size, learning rate, model channels, or scale factor, edit the corresponding settings in `train.py` and ensure that the dataset dimensions match the model output dimensions.
